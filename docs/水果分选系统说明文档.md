# 水果分选系统说明文档

> 适用对象：客户、操作员、实施与运维人员
> 更新日期：2026-07-21

---

## 1. 系统简介

本系统是一套运行在 **HarmonyOS（鸿蒙）平板/工控终端** 上的水果分选上位机软件，与分选线的 FSM 控制器（下位机）实时通信，完成以下工作：

- **设备配置管理**：出口设置、品质等级、大小等级、产品方案等参数的查看与下发；
- **实时分选监控**：各出口/等级的实时计数、重量统计，秒级刷新；
- **数据存储与追溯**：分选数据自动写入本地数据库，支持按日期、客户等条件的历史查询；
- **尾期处理与报表**：批次结束处理、分选报表生成与打印。

系统由三部分组成：

| 组成 | 说明 |
|---|---|
| 鸿蒙前端（ArkTS） | 操作界面，负责展示与人机交互 |
| Go 后端（libohos.so） | 业务核心，负责与 FSM 通信、数据解析、数据库读写 |
| C++ 桥接层（NAPI） | 连接前端与 Go 后端的中间层 |

三者打包在同一个鸿蒙应用内，**单机即可运行，不依赖外部服务器**。

## 2. 主要功能（面向客户/操作员）

### 2.1 主页（分选总览）

- 顶部固定显示 **9 个关键指标（KPI）卡片**，不随页面滚动移动，随时掌握分选总量、速度等核心数据；
- 分选信息卡片展示当前批次、产品方案等信息；
- 出口设置对话框：查看和修改各出口对应的等级分配；
- 产品设置对话框：切换水果品种、产品方案；
- 打印设置：配置报表打印相关参数。

### 2.2 品质设置

- 品质等级数据表：展示各品质等级（如优果、良果、次果）的判定参数；
- 品质参数设置对话框：调整颜色、瑕疵、UV 等品质判定阈值（含百分比与范围校验）；
- 品质等级参数选择对话框：为等级选择参与判定的参数项；
- 品质出口对话框：配置品质等级与物理出口的对应关系；
- 修改后的参数通过后端下发至 FSM 控制器实时生效。

### 2.3 等级（大小/重量）设置

- 等级数据表：展示各重量/大小等级的区间划分；
- 等级出口对话框：配置等级与出口的绑定关系；
- 支持等级区间的增删改，并同步下发到控制器。

### 2.4 实时统计

- 多页签（9 个页签）展示分选线的实时统计数据；
- 数据来源于 FSM 控制器周期上报的统计报文（约每秒刷新）；
- 后端每 **3 秒**将统计数据聚合写入本地数据库，掉电不丢失；
- 支持查看历史统计数据（历史统计加载器）。

### 2.5 历史查询

- 按 **日期区间** 查询历史分选记录；
- 按 **客户** 维度查询；
- 查询结果以数据表形式展示，可用于对账与追溯。

### 2.6 尾期处理（批次结束）

- 批次分选结束时进行尾期处理，含确认对话框与倒计时对话框，防止误操作；
- 生成处理记录卡片与尾期处理报表；
- 出口等级报表服务支持导出/打印分选结果汇总。

### 2.7 统计总览

- 独立的总览页面，汇总展示整线分选情况（48 通道版式）。

## 3. 系统架构（面向技术人员）

### 3.1 总体结构

```
┌─────────────────────────────────────────┐
│           鸿蒙应用（单进程）              │
│                                         │
│  ArkTS 前端页面（Home.ets 等）           │
│        │  import libentry.so            │
│  C++ NAPI 桥接（napi_init.cpp）          │
│        │  调用 Go 导出函数（C ABI）       │
│  Go 后端（libohos.so）                   │
│   ├─ CTCP 服务：与 FSM 控制器通信         │
│   ├─ WebSocket 服务：向前端推送数据       │
│   ├─ SQLite 数据库（GORM）               │
│   ├─ Modbus TCP 服务                    │
│   └─ OPC UA 服务                        │
└─────────────────────────────────────────┘
              │ TCP (CTCP协议)
        FSM 分选控制器（下位机）
```

### 3.2 数据流

1. **初始化**：应用启动后，前端调用 `GoInitORMWithPath()` 初始化数据库、`GoStartTCPServer()` 启动通信服务；
2. **配置同步**：
   - 前端通过 WebSocket 连接 `ws://127.0.0.1:18080/ws/data`；
   - 前端发送 `{"type":"requestStGlobal"}`；
   - Go 后端向 FSM 发送 DISPLAY_ON/SYNC 命令；
   - FSM 回复 `0x1000`（StGlobal 全量配置）；
   - Go 解析后以 JSON 经 WebSocket 推送给前端展示；
3. **实时统计**：FSM 周期发送 `0x1001`（StStatistics）→ Go 解析 → WebSocket 推送前端；
4. **数据落库**：Go 每 3 秒聚合统计数据，经 GORM 写入 SQLite。

### 3.3 通信协议

**CTCP 命令（与 FSM 控制器）：**

| 命令 ID | 内容 | 说明 |
|---|---|---|
| `0x1000` | StGlobal | 设备全量配置（出口、等级、方案等） |
| `0x1001` | StStatistics | 实时分选计数器 |
| `0x1002` | 等级信息 | 品质/大小等级设置 |

**WebSocket 帧格式（后端 → 前端）：**

```json
{
  "type": "data",
  "topic": "stglobal | statistics | grade",
  "data": { },
  "at": 1710000000000
}
```

| topic | 内容 |
|---|---|
| `stglobal` | 全量配置（StGlobal 结构） |
| `statistics` | 实时计数（StStatistics 结构） |
| `grade` | 等级/重量设置 |

**对外接口**：后端同时提供 Modbus TCP 与 OPC UA 服务，可供工厂 MES/SCADA 等第三方系统采集数据。

### 3.4 代码结构

**前端（e:/new/my_harmony）**，入口 `entry/src/main/ets/pages/Home.ets`：

| 目录 | 功能 |
|---|---|
| `pages/home/` | 主页：KPI 卡片、分选信息、出口/产品/打印设置 |
| `pages/quality/` | 品质等级设置 |
| `pages/level/` | 大小/重量等级设置 |
| `pages/realtime/` | 实时统计（多页签） |
| `pages/history/` | 历史查询（日期/客户） |
| `pages/endprocessing/` | 尾期处理与报表 |
| `pages/overview/` | 统计总览（48 通道） |

各模块内部统一采用 `core/`（DataManager / EventHandler / StateManager）分层，界面与逻辑分离。

**后端（e:/goTest/go/ohos）：**

| 目录/文件 | 功能 |
|---|---|
| `main.go` | C ABI 导出函数（`//export`） |
| `Tcp/ctcpserver.go` | CTCP 监听与命令分发 |
| `Tcp/websocket.go` | WebSocket 中心，前后端消息 |
| `Tcp/ctcp_structs.go` | StGlobal / StStatistics 结构定义 |
| `Tcp/realtime_save*.go` | 3 秒聚合与落库调度 |
| `database/` | GORM 模型、迁移、REST 路由 |
| `modbus/`、`opcua/` | 对外工业协议服务 |

## 4. 部署与运行（面向实施/运维）

### 4.1 环境要求

- 鸿蒙设备（arm64-v8a 架构），如鸿蒙平板或工控屏；
- 开发/编译环境：Windows + DevEco Studio + HarmonyOS SDK + Go 1.25+。

### 4.2 编译步骤

1. **编译 Go 后端**（修改 Go 代码后必须执行）：

   ```powershell
   .\go\ohos\build_ohos.ps1
   ```

   输出 `entry/libs/arm64-v8a/libohos.so`，并自动生成头文件 `libohos.h`。

2. **编译鸿蒙应用**：使用 DevEco Studio 或 hvigor 构建，原生模块（libentry.so）经 CMake 自动链接 libohos.so。

3. **部署**：通过 DevEco Studio 安装到设备。

### 4.3 现场配置要点

- 确认设备与 FSM 控制器在同一网段，CTCP 通信可达；
- WebSocket 为本机回环（127.0.0.1:18080），无需额外配置；
- 数据库为本机 SQLite 文件，路径由 `GoInitORMWithPath()` 指定；
- 如第三方系统需要采集数据，开放 Modbus TCP / OPC UA 对应端口。

### 4.4 测试

```powershell
cd go\ohos
go test ./...
```

## 5. 常见问题（FAQ）

**Q1：界面上没有配置数据/数据不刷新？**
依次检查：① 设备与 FSM 控制器网络是否连通；② 应用是否重启过（重启后会重新同步配置）；③ FSM 控制器是否正常上电运行。

**Q2：修改了等级/品质参数，控制器没有生效？**
参数保存后由后端经 CTCP 下发至 FSM，请确认通信正常；如仍无效，重新进入设置页触发一次配置同步（requestStGlobal）核对回读值。

**Q3：历史数据能保存多久？**
数据保存在设备本地 SQLite 数据库，容量受设备存储限制，建议定期导出报表归档。

**Q4：升级软件会丢数据吗？**
数据库文件独立于应用安装包，正常覆盖升级不影响历史数据；卸载重装前请先备份数据库文件。
